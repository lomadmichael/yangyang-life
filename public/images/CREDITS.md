# 사진 출처 (public/images)

- 모든 사진은 로마드협동조합 프로그램 기록 사진에서 골라 웹용으로 변환했다(크롭·리사이즈·자동 대비 50%, EXIF·위치 정보 제거, sRGB, JPEG q82 progressive).
- 생성 스크립트: `yangyang-photos/scripts/build_assets.py` (원본은 수정하지 않음)
- 장소는 사진 속 간판·이정표로 확인된 것만 적었다. 나머지는 "확인 필요".
- cover-*.jpg(홈 표지, v4)는 디자인 시안 `yangyang-design/out/v3/d/img/` 의 2400×1800 판을 다시 저장(q80, EXIF 없음), `-sm` 은 모바일용 세로 2:3 크롭(960×1440).
- faces: none = 사람 없음 / back_or_far = 뒷모습·원경만 (원본 긴 변 2000px로 직접 확인)
